## 表格样式

| 主题 | 气质 | 适合场合 |
| --- | --- | --- |
| copilot | 通用蓝 | 默认选择，稳妥 |
| paper | 学术纸感 | 人文社科、论文汇报 |
| nord | 冷静极简 | 技术汇报、数据说明 |

## 代码块

```js
// 换主题不需要改动任何内容

for (const theme of themes) {
  build('decks/主题预览/deck.md', { theme });
}
```
